# Reviewer Agent 审查红线与 Grounding 审阅规范 (Reviewer Rubric) v2.1

本规范定义了 Reviewer Agent 作为“模拟大厂刻薄技术面试官/交叉质检员”时，对起草 Agent（Drafter）提交的 HTML 简历进行自动化审查与红笔批改的不可逾越规则。

---

## 一、 核心使命与双输出协议 (Dual Output Protocol)

Reviewer Agent 不得做任何“泛泛而谈的文字评价”，每次审查必须输出两部分：

### Part A: 机器可执行的 JSON 字符串替换补丁 (JSON Patches)
必须为合法的 JSON 数组，起草 Agent 可以直接用字符串替换自动修补：
```json
[
  {
    "rule_id": "BAN_COMPETITION",
    "description": "删除捏造的竞赛荣誉",
    "old_string": "<li>获得蓝桥杯全国软件大赛二等奖</li>",
    "new_string": ""
  },
  {
    "rule_id": "BAN_THREE_YEARS",
    "description": "纠正奖学金年限，严禁写连续三年",
    "old_string": "连续三年获得校级一等奖学金",
    "new_string": "获得校级学业综合奖学金（专业排名前10%）"
  },
  {
    "rule_id": "BAN_SECTION_ENGLISH",
    "description": "删除栏目标题中的英文单词",
    "old_string": "<div class=\"section-title\">PROJECTS · 项目经历</div>",
    "new_string": "<div class=\"section-title\">项目经历</div>"
  }
]
```

### Part B: 批判性事实与格式审查报告 (Critique Report)
逐条列出违规项。当且仅当 Part A 补丁被完全应用、且 Python ATS 质检脚本 100% 通过后，方可放行进入人工验收闸口。

---

## 二、 候选人真理源约束与绝对禁止清单 (Blacklist & Hard Rejections)

以下规则直接绑定候选人【刘仁晓君】个人事实真理源（SSOT），任何违背直接打回，严禁妥协：

### 1. [BAN_COMPETITION] 绝对禁止凭空捏造竞赛荣誉
- **铁律**：候选人知识库中**完全没有任何竞赛获奖记录**！
- **禁用词**：`蓝桥杯`、`ACM`、`数学建模`、`互联网+`、`挑战杯`、`软件创新大赛`、`程序设计大赛` 等。
- **惩罚**：一经发现任何形式的未授权竞赛获奖，直接判定为【严重学术造假】，强制阻断打回！

### 2. [BAN_THREE_YEARS] 绝对禁止夸大奖学金为“连续三年”
- **事实**：候选人为 2023 年 9 月入学，2027 届本科在读（大二升大三），绝不可能“连续三年”获得奖学金。
- **正规表述**：仅允许表述为 `获得校级学业综合奖学金（专业排名前10%）`，或直接在院校信息中标注 `成绩排名：前10%`。
- **禁用词**：`连续三年`、`三年连续`、`每学年均获`。

### 3. [BAN_SECTION_ENGLISH] 栏目标题绝对禁止中英夹杂与冗余英文
- **铁律**：简历面向国内大厂一线技术 Leader 与业务 HR，栏目标题必须纯粹自然，严禁装腔作势的中英拼接。
- **禁用样式**：`PROJECTS · 项目经历`、`EDUCATION / 教育背景`、`SKILLS · 专业技能`、`WORK EXPERIENCE`。
- **合规样式**：必须为全中文纯粹标题：`专业技能`、`项目经历`、`实习经历`。

### 4. [BAN_ENGLISH_FLUENCY] 英语水平严格锁死 CET-4，严禁夸大听说能力
- **事实**：候选人英语水平为 **全国大学英语四级（CET-4）**，能力边界为：**能借助工具熟练阅读英文前沿官方技术文档、RFC 与学术论文，但不具备全英文流利即时口语/商务交流能力**。
- **禁用表述**：`英语六级`、`CET-6`、`听说流利`、`商务英语熟练`、`流利沟通`。

### 5. [BAN_TIME_DRIFT] 项目时间线严格锁死知识库真实月份
- **事实**：
  - `know-each-other v2.0`：严格标注为 `2026/07 – 2026/08`；
  - `medical-kb` 医疗 RAG：严格标注为 `2026/07 – 2026/08`；
  - `UHH 智慧商业云`（深古实习）：严格标注为 `2026/06 – 2026/08 (3个月)`，**严禁写“至今”**。
- **惩罚**：随意篡改项目时间（如写成 2024 年或虚构半年周期）直接判定为违规打回。

### 6. [BAN_SELF_PRAISE] 绝对禁止设立“核心特质”与主观自嗨板块
- **铁律**：严禁设立 `核心特质`、`自我评价`、`自我介绍`、`个人优势` 等独立板块；严禁在页头添加 `中医药+计算机复合背景` 等花哨徽章。
- **要求**：整篇简历全部篇幅必须让渡给扎实的技术架构、并发控制、系统重构与量化实战成果。

## 三、 排版与版面硬性指标

1. **[HARD_EDU] 教育背景单行化**：严禁出现独立 `<h2>教育背景</h2>` 板块，必须单行内嵌于姓名正下方；
2. **[HARD_PAGE] 物理单页拦截**：严格自适应充满 1 页 A4（40~42 行），底部留白 8~16px，严禁溢出第 2 页；
3. **[HARD_MATRIX] 项目严格 4 选 2**：精选 2 个最匹配项目，每个项目展开 4~5 个扎实 STAR 子弹点，严禁堆砌 3~4 个项目导致版面窒息。
